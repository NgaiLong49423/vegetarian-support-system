# README Reference

Use this reference for the repository's primary entry point.

## Responsibility

README should help a new reader answer quickly:

- What is this project?
- What problem does it solve?
- What is its current high-level status when the repository tracks one?
- What is the main technology stack?
- What is the quickest confirmed way to get started?
- Where are the authoritative detailed documents?

## Keep README as an Entry Point

Prefer concise summaries and links to detailed sources of truth, for example:

- SRS / requirements
- architecture
- API guide/contract
- setup guide
- development guide
- contributing guide

Do not copy the full SRS, architecture, API contract, setup guide, or development workflow into README.

## Quick Start

A brief quick-start may be included when it remains stable and does not duplicate a long setup process.
Otherwise link to the setup guide.
