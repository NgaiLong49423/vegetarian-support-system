# BUG-060 — Snapshot OpenAPI thiếu API hướng dẫn nấu đã có trên develop

- **Trạng thái:** `RECORDED`
- **Khu vực:** Backend/AI/OpenAPI
- **Mức độ:** Chưa xác định
- **Ngày phát hiện:** 2026-10-23
- **Ngày cập nhật:** 2026-10-23
- **Ngữ cảnh:** Đồng bộ nhánh `fix/158-recipe-image-storage` của PR #162 với `origin/develop` tại `31296cd`; endpoint được thêm bởi commit `adfbcd9`.
- **Issue liên quan:** Chưa có Issue riêng.

## Triệu chứng và hành vi mong đợi

Snapshot `docs/api/openapi.yaml` phải phản ánh contract do Backend cùng source sinh ra. Baseline `origin/develop` có `AiCookingGuideController` nhưng snapshot chưa có `POST /api/v1/recipes/ai/cooking-guide` và hai schema `AiCookingGuideRequest`, `AiCookingGuideResponse`.

## Bằng chứng và tái hiện

1. Đọc controller tại `app/mamxanh-backend/src/main/java/tech/mamxanh/recipe/controller/AiCookingGuideController.java` trên `origin/develop`.
2. Đối chiếu `git show origin/develop:docs/api/openapi.yaml`: không có path và hai schema trên.
3. Build source đã đồng bộ bằng root Docker Compose project `mamxanh-dev`, lấy `/v3/api-docs.yaml` qua `scripts/export-openapi.ps1`: runtime có path cùng hai schema này.
4. Snapshot sau merge tự động khác runtime ở `paths` và `components`; snapshot được sinh lại khớp runtime khi so sánh cấu trúc YAML.

## Môi trường và nguyên nhân

Windows, Docker Desktop Linux containers, root Compose, Spring Boot. Nguyên nhân cụ thể khiến snapshot baseline chưa được cập nhật: chưa xác định. Chênh lệch không phải endpoint mới của Issue #158.

## Cách xử lý

Trong phạm vi đồng bộ contract của PR #162, đã chạy script sinh OpenAPI chính thức từ Backend sau tích hợp; không sửa endpoint thủ công. Baseline trên GitHub chưa được thay đổi bởi thao tác local này.

## Kiểm chứng

Snapshot sinh lại khớp `/v3/api-docs.yaml` theo cấu trúc YAML; upload ảnh vẫn có response `201` và `503`. Chưa có commit/push hoặc CI xác nhận bản đồng bộ này; bản ghi giữ `RECORDED`.
