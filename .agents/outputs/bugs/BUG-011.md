# BUG-011 — Nút Stop của IntelliJ không truyền env file cho Docker Compose

- Trạng thái: `RECORDED`
- Khu vực: Development/IntelliJ Docker
- Mức độ: Medium
- Ngày phát hiện/cập nhật: 2026-10-05
- Bối cảnh: thiết lập Run Docker từ root; nhánh `develop`, HEAD `36574c0`, cấu hình `.run/` chưa commit.
- Requirement/Issue/PR: Chưa xác định.

## Triệu chứng và hành vi mong đợi

Sau khi Run `MamXanh Docker Compose` thành công với env file của Backend, nút Stop trong Services phải dừng stack `mamxanh-dev` và giữ SQL volume.

## Hành vi thực tế và bằng chứng

IntelliJ chạy `docker compose -f <root>/docker-compose.yml -p mamxanh-dev stop` mà không truyền `--env-file app/mamxanh-backend/.env`. Console báo biến `MAMXANH_JWT_SECRET` thiếu giá trị, exit code 1. SQL, Backend và Frontend vẫn running/healthy sau thao tác.

Lệnh `docker compose -p mamxanh-dev --env-file app/mamxanh-backend/.env stop` chạy thành công. `ps -a` xác nhận mọi service đã exited; `mamxanh-dev_sqlserver-data` vẫn tồn tại, giữ nguyên thời điểm tạo `2026-10-05T14:15:43Z`.

## Tái hiện và môi trường

1. Windows, IntelliJ IDEA với Docker plugin `262.10315.125`, Docker Desktop Linux containers.
2. Run cấu hình Compose của dự án với env file nằm tại Backend; chờ stack healthy.
3. Trong Services chọn `Docker-compose: mamxanh-dev`, bấm Stop.
4. Đọc lỗi interpolation và kiểm tra services vẫn chạy.

## Nguyên nhân

Lệnh Stop quan sát được thiếu env file đã dùng khi Run. Nguyên nhân bên trong plugin chưa xác định; chưa kết luận lỗi upstream hay thiếu tùy chọn cấu hình khác.

## Xử lý và xác minh

Chưa bắt đầu sửa tích hợp nút Stop. Workaround có kiểm chứng: dùng lệnh Compose stop kèm env file ở trên. Không xóa volume hoặc lưu secret trong bản ghi.
