# BUG-119 — Docker CI báo contract OpenAPI lệch snapshot

- **Trạng thái:** TRACKING
- **Khu vực:** Backend/API/OpenAPI CI
- **Mức độ:** Chưa xác định
- **Ngày phát hiện:** 2026-11-21
- **Ngày cập nhật:** 2026-11-21
- **Bối cảnh:** Điều tra Docker Development CI thất bại trên PR #237.
- **Nhánh/commit:** `codex/unify-ai-package-access`, `1fc739611307320d41118f7bc56d4c6bf55be72b`.
- **Yêu cầu/Issue:** Chưa xác định.

## Hiện tượng và mong đợi

OpenAPI snapshot được commit cần khớp contract Backend được sinh trong cùng commit để người dùng và CI thấy đúng API runtime.

## Thực tế và bằng chứng

Docker Development job `136565387611` chạy xong Playwright với 15 test đạt và 12 test bỏ qua, sau đó thất bại ở bước đối chiếu contract với thông báo `docs/api/openapi.yaml differs from the generated Backend OpenAPI contract.`

## Tái hiện và môi trường

Chạy workflow Docker Development cho PR #237 tại commit `1fc739611307320d41118f7bc56d4c6bf55be72b`.

## Nguyên nhân

Snapshot OpenAPI không được cập nhật sau khi annotation API trong nhánh thay đổi.

## Xử lý

Đã thay snapshot bằng artifact `openapi-runtime.yaml` do chính job CI sinh từ commit này. Không sửa nội dung YAML thủ công.

## Xác minh

SHA-256 của `docs/api/openapi.yaml` trùng hoàn toàn với SHA-256 của artifact runtime tải từ job cùng commit. Chưa chạy lại Docker Development trên commit mới.
