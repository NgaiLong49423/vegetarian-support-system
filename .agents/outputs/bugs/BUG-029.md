# BUG-029 — Schema bình chọn không chấp nhận currentReaction null dù API trả giá trị này

- **Trạng thái:** `RECORDED`
- **Khu vực:** Backend/Recipe Reaction/OpenAPI
- **Mức độ:** Medium
- **Ngày phát hiện/cập nhật:** 2026-10-15
- **Ngữ cảnh:** Đồng bộ PR #119 / Issue #56 với develop `7ae8d2a`, xuất snapshot từ root Compose project `mamxanh-fr57-sync`.
- **Source:** HEAD `2456508` cùng phần merge develop đang kiểm tra; Controller/DTO bình chọn không đổi trong merge mới.

## Triệu chứng

Schema `components.schemas.RecipeReactionResponse.properties.currentReaction` khai báo `type: [string, 'null']` nhưng `enum` chỉ gồm `LIKE`, `DISLIKE`. Response chưa có hoặc đã hủy bình chọn trả `currentReaction=null`. Client kiểm tra JSON Schema nghiêm ngặt có thể từ chối response hợp lệ về nghiệp vụ.

## Kết quả mong đợi

Generated contract phải chấp nhận `LIKE`, `DISLIKE` và giá trị JSON null mà API trả khi chưa bình chọn hoặc sau DELETE; vẫn từ chối các chuỗi khác.

## Bằng chứng

- Đọc `/v3/api-docs` từ Backend Compose ngày 2026-10-15 và snapshot YAML sinh bằng `scripts/export-openapi.ps1`: `type` có `null`, `enum` không có null.
- `RecipeReactionService.get` dùng null khi không có bản ghi; `remove` trả null. `RecipeReactionIntegrationTest.memberSetsSwitchesRemovesAndReadsPersistedChoice` kiểm tra response null trước Like và sau DELETE; Backend CI run `38740323179` pass.
- Theo [JSON Schema enum](https://json-schema.org/understanding-json-schema/reference/enum), giá trị phải thuộc tập enum; việc cho phép null ở type không mở rộng tập enum.
- Scalar CLI 2.5.2 validate cấu trúc spec pass; điều đó không xác nhận response null đáp ứng schema này.

## Tái hiện

1. Đọc property trên trong generated OpenAPI.
2. Đọc phản hồi của Member chưa bình chọn, hoặc DELETE lựa chọn hiện tại.
3. Đối chiếu `currentReaction=null` với enum chỉ chứa hai chuỗi.

## Môi trường và nguyên nhân

Springdoc/OpenAPI 3.1 trên Backend Java 21 trong Compose. Schema sinh từ field enum nullable hiện tại; chưa xác định bản vá annotation/customizer phù hợp.

## Cách xử lý

Chưa bắt đầu. Cần sửa nguồn annotation/schema generation và thêm kiểm tra response null theo contract; không sửa tay YAML generated. Nhiệm vụ hiện tại xử lý xung đột và CI, không tự mở GitHub Bug Issue hoặc thay business behavior.

## Kiểm chứng

Chưa sửa, chưa có bằng chứng RESOLVED.
