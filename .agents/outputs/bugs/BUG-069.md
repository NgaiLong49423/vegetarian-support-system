# BUG-069 — Script kiểm chứng fixture không đọc danh sách recipe dạng JSON

- **Trạng thái:** `RESOLVED`
- **Khu vực:** Database/Demo/Verification
- **Mức độ:** Low
- **Ngày phát hiện:** 2026-10-29
- **Ngày cập nhật:** 2026-10-29
- **Nhánh/commit:** `feature/database-data`, `8c77adb0`
- **Yêu cầu liên quan:** FR-18; chưa có Bug Issue riêng.

## Bối cảnh và mong đợi

Phát hiện khi chạy `scripts/verify-demo-ingredient-fixtures.ps1` để kiểm chứng repeatable seed dữ liệu nguyên liệu. Script cần đọc đủ tên của 54 recipe fixture trước khi gửi SQL kiểm tra vào SQL Server.

## Thực tế và bằng chứng

Script dừng với `Expected exactly 54 named fixture recipes.` trước khi gọi Docker/SQL Server. Bộ regex cũ tìm `INSERT INTO @recipes ... VALUES`; seed hiện tại nạp JSON bằng `OPENJSON`, nên regex trích được 0 tiêu đề.

## Nguyên nhân

Verifier chưa được cập nhật theo định dạng JSON hiện tại của `R__demo_sample_data_46_recipe_seasonings.sql`.

## Tái hiện

Tại repository root, chạy `./scripts/verify-demo-ingredient-fixtures.ps1` với PowerShell. Lỗi xảy ra trước bước truy cập Compose SQL Server.

## Môi trường

Windows PowerShell trong repository trên nhánh `feature/database-data`, ngày 2026-10-29. Trạng thái Docker/SQL chưa liên quan vì verifier dừng ở bước phân tích file.

## Cách xử lý

Verifier được đổi sang trích JSON `@recipe_json` rồi phân tích bằng `ConvertFrom-Json`, đồng thời giữ kiểm tra chính xác 54 tiêu đề recipe.

## Kiểm chứng

Ngày 2026-10-29: PowerShell parser pass và bước trích xuất trả về đủ 54 recipe. Chạy tiếp verifier đi đến lệnh Docker; SQL kiểm chứng chưa chạy vì Docker Engine không có named pipe `dockerDesktopLinuxEngine` trong môi trường này.
