## Biểu hiện

API danh sách và chi tiết tính tỷ lệ Like với hai chữ số thập phân, khác phép làm tròn thành số nguyên theo SRS và API phản hồi mới.

## Kết quả mong đợi

10 Like và 1 Dislike phải trả tỷ lệ 91%; ba API trả cùng ý nghĩa số liệu. Không có vote trả `null`, toàn Dislike trả `0`.

## Kết quả thực tế trước sửa

`RecipePostService.assembleResponse` và `RecipeService.getPublishedRecipe` dùng `divide(..., 2, RoundingMode.HALF_UP)`, nên 10/11 × 100 trả `90.91`. Giai đoạn 2 API phản hồi đã trả `91` nhưng hai đường đọc này chưa đồng bộ.

## Bằng chứng

- AC-57.1 và BR-69 quy định làm tròn tỷ lệ.
- Hai service trên baseline `4ff1505` dùng scale 2; đây là bằng chứng từ code trước sửa, không phải kết quả browser trước sửa.
- Kiểm tra sau sửa trên source working tree xác nhận cả reaction, browse và detail trả `91` cho cùng fixture 10 Like/1 Dislike.

## Cách tái hiện

1. Dùng database kiểm thử, chuẩn bị một Recipe Post công khai có 10 Like và 1 Dislike.
2. Gọi GET `/api/v1/recipes` và GET `/api/v1/recipes/{recipeId}`.
3. Trước sửa, hai đường tính tỷ lệ dùng scale 2; sau sửa giá trị `likePercentage` là `91`.

## Môi trường

Java 21; Spring Boot; SQL Server local 2019. Backend working tree chạy profile `local` tại port 8081, không bật `local-reset`. Docker chưa khả dụng.

## Nguyên nhân

Phép tính tỷ lệ bị lặp ở các service và sử dụng số chữ số thập phân khác nhau.

## Cách xử lý

Ba service dùng chung `RecipeReactionStatistics.likePercentage`, làm tròn HALF_UP với scale 0; giữ nguyên kiểu dữ liệu DTO và thuật toán xếp hạng.

## Kiểm chứng

- Ngày 2026-10-11: 44/44 unit/regression tests pass, gồm biên 12,5% → 13%, no-vote, all-dislike và mapping response.
- 45 kiểm tra HTTP/SQL Server local thật pass, gồm ba API thống nhất ở các trạng thái `null`, `0` và `91`; bài HIDDEN/DELETED bị loại khỏi MOST_LIKED/MOST_ACTIVE/TRENDING.
- Fixture riêng đã được dọn. Chưa xác minh browser, Testcontainers/Compose, CI hay full coverage gate; trạng thái RESOLVED chỉ xác nhận lỗi tính tỷ lệ Backend này, không xác nhận FR-57 đã nghiệm thu toàn bộ.
