# BUG-047 — Upload ảnh trả thành công bằng URL giả khi Azure chưa được cấu hình

- **Trạng thái:** `RESOLVED`
- **Khu vực:** Backend/Frontend/Docker/Azure Storage
- **Mức độ:** Chưa xác định
- **Ngày phát hiện:** 2026-10-19
- **Ngày cập nhật:** 2026-10-19
- **Ngữ cảnh:** Kiểm tra ảnh công thức do người dùng tạo, FR-14, [Issue #158](https://github.com/NgaiLong49423/vegetarian-support-system/issues/158), nhánh `fix/158-recipe-image-storage`, implementation commit `c3a5155`, [PR #162](https://github.com/NgaiLong49423/vegetarian-support-system/pull/162).

## Triệu chứng và hành vi mong đợi

Ảnh mới không hiển thị dù upload báo thành công và SQL có bản ghi media. Mong đợi upload thành công phải lưu nội dung ảnh thật và trả URL mở được; lỗi cấu hình/storage phải được báo rõ.

## Bằng chứng và tái hiện

Trước sửa, thiếu connection string khiến `StorageConfig` dùng `MockStorageClient`. Client chỉ tạo URL và ghi nhớ MIME trong RAM, không ghi nội dung ảnh. Root Compose chưa truyền biến Azure vào Backend. Các công thức TEST54-1-A và TEST54-1-B có media/ảnh bìa nhưng URL mock không phân giải DNS trong lần kiểm tra; không kết luận HTTP 404 cho các URL này. Ảnh seed dùng asset/URL công khai nên vẫn hiện.

Tái hiện: chạy Backend thiếu Azure, Expert chọn ảnh và đăng công thức; upload nhận 201 với URL giả. Frontend trước sửa cũng tính ảnh xem trước khi upload lỗi vào số ảnh đã tải.

## Môi trường và nguyên nhân

Windows, root Compose, SQL Server, React và Spring Boot. Fallback mock trong cấu hình runtime che mất lỗi storage; frontend không phân biệt đủ trạng thái xem trước và tải thành công. Lỗi khác với BUG-020/Issue #117 về đọc sai envelope response cũ.

## Xử lý

Truyền biến Azure qua Compose; thay fallback bằng `UnavailableStorageClient`, trả 503 khi storage thiếu/lỗi; không ghi chi tiết lỗi SDK nhạy cảm. Frontend đánh dấu ảnh lỗi, đếm ảnh thành công, chặn xuất bản khi đang tải hoặc còn preview lỗi. Đồng bộ OpenAPI 201/503. Không khôi phục được nội dung ảnh chỉ có URL mock cũ; cần tải lại.

## Kiểm chứng

Ngày 2026-10-19: 7 Playwright UI test đạt; 6 `RecipeMediaAuthorizationIntegrationTest` đạt trên SQL Server Testcontainers; các test storage/media tập trung đạt. Cleanup xóa blob (GET trả 404), media và công thức fixture. Bằng chứng local không đồng nghĩa Issue được đóng hoặc CI đã đạt.
