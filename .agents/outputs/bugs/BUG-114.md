# BUG-114 — Script kiểm chứng đòi sai số lượng công thức fixture

- **Trạng thái:** RESOLVED
- **Khu vực:** Backend/Database/Demo Fixtures
- **Mức độ:** Low
- **Ngày phát hiện:** 2026-11-21
- **Ngày cập nhật:** 2026-11-21
- **Bối cảnh:** Trong lúc gỡ công thức xấu ảnh khỏi fixture repeatable demo và cập nhật số lượng recipe.
- **Nhánh/commit:** Chưa xác định
- **Yêu cầu/Issue:** Issue riêng chưa xác định

## Hiện tượng và mong đợi

`verify-demo-ingredient-fixtures.ps1` phải chấp nhận đúng số lượng tiêu đề mà `R__demo_sample_data_46_recipe_seasonings.sql` hiện khai báo.

## Bằng chứng hiện có

- Trước thay đổi, danh sách JSON trong `R__demo_sample_data_46_recipe_seasonings.sql` có 52 tiêu đề, nhưng script kiểm chứng yêu cầu 54.
- Guard SQL cũng đang yêu cầu 52 mục.
- Sau khi gỡ một công thức theo yêu cầu người dùng, danh sách JSON còn 51; script và guard SQL đã được đồng bộ về 51.

## Tái hiện

1. Đếm các phần tử trong JSON `@recipe_json` của seed R__46.
2. So sánh với điều kiện `$titles.Count -ne ...` trong script kiểm chứng.
3. Trước sửa, hai giá trị là 52 và 54, khiến script ném lỗi trước khi xác minh fixture database.

## Môi trường

Windows PowerShell; kiểm tra source Flyway local demo.

## Nguyên nhân

Số lượng mong đợi trong script kiểm chứng đã lỗi thời so với danh sách recipe trong repeatable fixture.

## Xử lý

Cập nhật script kiểm chứng và guard SQL về 51 sau khi loại một fixture recipe theo yêu cầu.

## Kiểm chứng

Kiểm tra tĩnh xác nhận JSON có 51 title, script mong đợi 51, SQL target guard là 51, và công thức đã gỡ không còn trong JSON fixture. Chưa chạy kiểm chứng tích hợp với SQL Server local.
