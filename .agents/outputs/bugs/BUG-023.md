# BUG-023 — Formatter oxfmt làm mất dấu phân cách trong type TypeScript viết một dòng

- **Trạng thái:** `RECORDED`
- **Khu vực:** Frontend/Tooling
- **Mức độ:** Medium
- **Ngữ cảnh phát hiện:** Kiểm tra TypeScript toàn bộ Frontend sau bước format giao diện FR-09.
- **Nhánh/commit:** `feature/15-weekly-meal-planning`, thay đổi chưa commit trên baseline `ae14879`.
- **Requirement/Issue/PR:** Phát hiện khi thực hiện [Issue #15 / FR-09](https://github.com/NgaiLong49423/vegetarian-support-system/issues/15); chưa có Issue sửa formatter hoặc PR riêng.
- **Ngày phát hiện:** 2026-10-13
- **Ngày cập nhật:** 2026-10-13

## Triệu chứng

Sau khi chạy formatter hiện có của Frontend, `npm.cmd run lint` báo `TS1005: ';' expected` tại khai báo `Target` trong `MealPlanWeekEditor.tsx`. Lỗi được tái hiện độc lập bằng một type nhỏ, không phụ thuộc React hoặc Backend.

## Hành vi mong đợi

Formatter giữ nguyên ý nghĩa và cú pháp TypeScript hợp lệ của đầu vào; format không làm chương trình mất khả năng typecheck.

## Hành vi thực tế

Đầu vào hợp lệ:

```typescript
type Target = { mealDate: string; mealType: string; entry?: number };
```

Đầu ra của `oxfmt 0.2.0`:

```typescript
type Target = { mealDate: string mealType: string entry?: number }
```

Hai dấu phân cách giữa các trường bị bỏ, nhưng các trường vẫn cùng một dòng. TypeScript từ chối đầu ra.

## Bằng chứng

- Binary component-local `app/mamxanh-frontend/node_modules/.bin/oxfmt.cmd --version` trả `Version: 0.2.0`.
- Đã tạo đầu vào tối giản tại `.agents/outputs/fr09-stage5/formatter-repro.ts` và chạy binary trên đường dẫn tuyệt đối; formatter báo đã format một file.
- `tsc.cmd --noEmit --skipLibCheck` trên đầu ra báo `TS1005` tại cột 34 và 51, exit code 1.
- Type `Target` của màn lịch được chuyển sang nhiều dòng; `npm.cmd run lint` sau đó exit code 0. Đây là biện pháp tránh lỗi cho FR-09, không phải bằng chứng formatter đã được sửa.

## Tái hiện

1. Trong workspace Frontend, tạo một file `.ts` với đầu vào hợp lệ ở trên.
2. Chạy binary `node_modules/.bin/oxfmt.cmd` hiện có trên đường dẫn tuyệt đối của file. Binary này từ chối đường dẫn có `..`.
3. Đọc đầu ra và chạy `node_modules/.bin/tsc.cmd --noEmit --skipLibCheck` trên cùng file.
4. Kiểm tra dấu phân cách bị mất và lỗi `TS1005`.

## Môi trường

Windows, PowerShell; formatter component-local phiên bản 0.2.0; TypeScript từ dependency hiện có của Frontend. Không thay đổi dependency để thực hiện tái hiện.

## Nguyên nhân

Đã xác nhận formatter tạo đầu ra sai cú pháp cho mẫu trên. Nguyên nhân trong mã nguồn formatter chưa xác định.

## Cách xử lý

Trong FR-09, giữ khai báo type thành nhiều dòng để source typecheck được. Chưa sửa hoặc nâng cấp công cụ formatter.

## Kiểm chứng

Lỗi formatter vẫn ở trạng thái `RECORDED`. Chưa có bằng chứng công cụ được sửa. TypeScript của ứng dụng đã pass sau biện pháp tránh lỗi cục bộ.
