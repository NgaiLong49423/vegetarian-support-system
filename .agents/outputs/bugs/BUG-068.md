## Triệu chứng

Backend biên dịch xong và kết nối SQL Server, nhưng dừng khi Flyway chạy migration V26. SQL Server báo `Invalid column name 'source_type'` và Flyway rollback migration.

## Hành vi mong đợi

Flyway áp dụng V26 thành công trên schema V25 để Backend hoàn tất khởi động.

## Bằng chứng

- Log Maven/Spring Boot do người dùng cung cấp ghi `Migrating schema [dbo] to version "26 - standard recipe units and conversion provenance"` rồi báo `SQL State: S0001`, `Error Code: 207`, `Message: Invalid column name 'source_type'`.
- Migration V26 ban đầu thêm cột `source_type` rồi tạo `CHECK` constraint tham chiếu cột đó trong cùng batch SQL Server.

## Cách tái hiện

1. Khởi động Backend từ schema V25 bằng migration V26 chứa `CHECK (source_type ...)` ngay sau lệnh `ALTER TABLE ... ADD source_type`.
2. Quan sát Flyway thất bại với lỗi SQL Server 207 `Invalid column name 'source_type'`.

## Môi trường và nguyên nhân

- **Môi trường:** SQL Server 2019; log khởi động ngày 2026-10-27.
- **Nguyên nhân:** SQL Server biên dịch tham chiếu của constraint trong batch trước khi cột vừa thêm khả dụng cho tham chiếu đó.

## Cách xử lý

Theo yêu cầu cập nhật mới, bỏ toàn bộ metadata nguồn khỏi quy đổi. Cột và constraint `source_type` đã được loại khỏi migration V26 và schema mới, nên không còn câu lệnh gây lỗi này.

## Kiểm chứng

- Backend test mục tiêu đạt 91/91 sau thay đổi DTO, entity và repository.
- Chưa chạy lại migration V26 trên SQL Server hoặc xác nhận khởi động ứng dụng sau sửa; trạng thái giữ `TRACKING` đến khi có bằng chứng runtime.
