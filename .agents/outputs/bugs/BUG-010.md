# BUG-010 — Cấu hình local lưu mật khẩu SQL Server dạng plaintext

- **Status:** `RECORDED`
- **Severity:** High
- **Area:** Backend/Configuration Security
- **Detected:** 2026-09-28
- **Related Issue:** Unknown

## Bối cảnh phát hiện

Phát hiện trong lúc khởi động Backend và chạy integration test SQL Server cho Issue #24 (FR-18).

## Hành vi kỳ vọng

Thông tin xác thực cơ sở dữ liệu không được hard-code hoặc commit trong tệp cấu hình theo dõi bởi Git. Cấu hình local cần nhận bí mật từ environment variable, secret store hoặc cơ chế cấu hình ngoài repository.

## Hành vi thực tế

Tệp `app/mamxanh-backend/src/main/resources/application-local.properties` đang chứa trực tiếp giá trị `spring.datasource.username` và `spring.datasource.password`.

## Bằng chứng

- Đọc trực tiếp tệp cấu hình local ngày 2026-09-28 xác nhận hai key credential có giá trị plaintext.
- Backend sử dụng tệp này khi profile `local` được kích hoạt; integration test đã kết nối SQL Server qua cấu hình này.

Không ghi lại giá trị credential trong bản ghi lỗi này.

## Cách tái hiện

1. Mở `app/mamxanh-backend/src/main/resources/application-local.properties`.
2. Quan sát các key `spring.datasource.username` và `spring.datasource.password` có giá trị trực tiếp trong tệp.

## Môi trường

- Repository: Mâm Xanh
- Backend: Spring Boot
- Profile: `local`
- Database: Microsoft SQL Server
