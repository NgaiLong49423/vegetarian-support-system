# BUG-009: Seed Docker lỗi do QUOTED_IDENTIFIER tắt

- Trạng thái: RESOLVED
- Khu vực: Backend/Database seed
- Mức độ: Medium
- Ngày phát hiện: 2026-10-03
- Nhánh/commit: `feature/40-nutrition-profile-metrics` / `1c4a246`
- Requirement/Issue/PR: PR #79; Issue liên quan chưa xác định

## Triệu chứng

Docker Development dừng khi service `sample-data` nạp `database/sample-data.sql` vào SQL Server 2019.

## Kỳ vọng

Seed chạy thành công sau khi Flyway tạo schema để Compose đưa Frontend lên.

## Thực tế

Service `sample-data` thoát mã 1; Docker Development gate thất bại.

## Bằng chứng

- GitHub Actions run [37086452234](https://github.com/NgaiLong49423/vegetarian-support-system/actions/runs/37086452234) cho thấy SQL Server và Backend khỏe, còn `sample-data` thoát mã 1.
- Log `sqlcmd` báo `Msg 1934` tại dòng 9: INSERT thất bại do SET option `QUOTED_IDENTIFIER` không đúng khi bảng có filtered index.

## Tái hiện

Chạy `database/sample-data.sql` bằng SQL Server 2019 với kết nối `sqlcmd` mặc định trong service `sample-data`.

## Môi trường

GitHub Actions, SQL Server 2019 image `2019-CU32-GDR11-ubuntu-20.04`, Compose service `sample-data`.

## Nguyên nhân gốc

`sqlcmd` không bật `QUOTED_IDENTIFIER`; script seed INSERT vào `[USER]`, bảng có filtered index.

## Cách xử lý

Đã thêm `SET QUOTED_IDENTIFIER ON` trước transaction trong `database/sample-data.sql`.
