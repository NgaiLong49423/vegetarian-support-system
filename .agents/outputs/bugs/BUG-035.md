# BUG-035 — OpenAPI lượt xem mô tả sai schema phản hồi lỗi

- **Trạng thái:** `RESOLVED`
- **Khu vực:** Backend/Recipe Views/OpenAPI
- **Mức độ:** Medium
- **Ngữ cảnh:** Đồng bộ FR-58 với develop `7ae8d2a`, PR #123, Issue #57.
- **Ngày phát hiện:** 2026-10-15
- **Ngày cập nhật:** 2026-10-16

## Triệu chứng và hành vi mong đợi

Generated OpenAPI phải mô tả response lỗi đúng content type và schema của `GlobalExceptionHandler`.

## Bằng chứng và cách tái hiện

Stack root Compose `mamxanh-fr58-sync`, Windows/Docker Linux, source FR-58 sau merge chưa commit: đọc `/v3/api-docs`, operation `POST /api/v1/recipes/{recipeId}/views`. Các mã 400/401/403/404/503 đều khai báo `application/json`, `$ref: RecipeViewResponse`. Gửi POST `/api/v1/recipes/0/views` với `{}` thực tế nhận 400, `application/problem+json`, các field `detail`, `instance`, `status`, `title`, `code=VALIDATION_FAILED`; không có `recipeId/counted/viewCount`.

## Nguyên nhân

Annotation chỉ khai báo description/status nên Springdoc suy schema từ kiểu trả về thành công.

## Xử lý và kiểm chứng

Đã bổ sung annotation `ProblemDetail` cho các mã lỗi và assertion generated contract. Kiểm chứng ngày 15/10: 7/7 `RecipeViewControllerTest` đạt, gồm assertion schema và media type cho cả 5 mã lỗi; runtime sau rebuild Compose trả đúng các schema, Scalar 2.5.2 xác nhận YAML OpenAPI 3.1 hợp lệ. Không tạo GitHub Bug Issue.

## Lịch sử định danh

Đổi từ BUG-032 trên nhánh FR-58 sang BUG-035 ngày 2026-10-16 khi đồng bộ develop, vì develop đã dùng BUG-032 cho lỗi phân quyền Administrator. Giữ nguyên bằng chứng, trạng thái và ngày phát hiện.
