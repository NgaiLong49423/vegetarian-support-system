## Biểu hiện

Hướng dẫn database ghi ERD chưa tồn tại, dù thư mục ERD đã có baseline conceptual được xác nhận gồm 23 thực thể và nguồn Draw.io conceptual/logical.

## Kết quả mong đợi

`database/README.md` mô tả đúng trạng thái ERD, phân biệt baseline conceptual đã duyệt với thiết kế logical/physical còn ở dạng nháp.

## Kết quả thực tế

Mục `Trạng thái thiết kế` ghi: `ERD và danh sách migration chưa tồn tại.`

## Bằng chứng

- `database/README.md` ghi ERD chưa tồn tại.
- `docs/diagrams/ERD/README.md` mô tả baseline conceptual đã duyệt gồm 23 thực thể lõi.
- Có file `docs/diagrams/ERD/conceptual-erd-v1.0.0.drawio`.
- Có file `docs/diagrams/ERD/logical-erd-v0.1.0.drawio` trong working tree dưới dạng nháp; điều này không có nghĩa file đã được commit.

## Cách tái hiện

1. Đọc mục `Trạng thái thiết kế` trong `database/README.md`.
2. Đối chiếu phần baseline conceptual trong `docs/diagrams/ERD/README.md`.
3. Xem danh sách file trong `docs/diagrams/ERD/`.
4. Nhận thấy hướng dẫn database không khớp với sơ đồ hiện có.
