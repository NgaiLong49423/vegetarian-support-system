# BUG-001 — Database guide incorrectly states that the ERD does not exist

- **Status:** RECORDED
- **Area:** Documentation/Database
- **Severity:** Medium
- **Detected:** 2026-09-20
- **Updated:** 2026-09-20
- **Detection context:** Reviewing the placement of the 23 conceptual entities before Backend implementation.
- **Branch/Commit:** Unknown
- **Requirement:** Unknown
- **Issue:** Unknown
- **PR:** Unknown

## Symptom

The database workspace guide reports that the ERD does not exist even though the maintained ERD workspace contains a confirmed 23-entity conceptual baseline and both conceptual and logical Draw.io sources.

## Expected behavior

`database/README.md` should describe the current ERD state accurately and distinguish the approved conceptual baseline from the draft logical/physical design state.

## Actual behavior

The `Trạng thái thiết kế` section states: `ERD và danh sách migration chưa tồn tại.`

## Evidence

- `database/README.md` states that the ERD does not exist.
- `docs/diagrams/ERD/README.md` documents an approved conceptual baseline containing exactly 23 core entities.
- `docs/diagrams/ERD/conceptual-erd-v1.0.0.drawio` exists.
- `docs/diagrams/ERD/logical-erd-v0.1.0.drawio` exists as a draft logical model.

## Reproduction

1. Open `database/README.md` and read the `Trạng thái thiết kế` section.
2. Open `docs/diagrams/ERD/README.md` and inspect the conceptual baseline section.
3. List the files under `docs/diagrams/ERD/`.
4. Observe that the database guide contradicts the current maintained ERD artifacts.

## Environment

Repository working tree on 2026-09-20.

## Root cause

Unknown. The database guide appears not to have been updated after the ERD artifacts were created and registered.

Not started.
