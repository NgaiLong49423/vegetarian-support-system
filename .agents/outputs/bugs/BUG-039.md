# BUG-039 — Hostname của healthcheck làm lệch server URL trong OpenAPI

- **Trạng thái:** `TRACKING`
- **Khu vực:** Docker/Backend/OpenAPI
- **Mức độ:** Medium
- **Ngày phát hiện:** 2026-10-17
- **Ngày cập nhật:** 2026-10-17
- **Bối cảnh:** Điều tra Docker Development của PR #149 theo yêu cầu người dùng.
- **Nhánh/commit:** `fix/142-verified-pro-payment`, baseline `37814bb`.
- **Requirement/Issue:** Hợp đồng OpenAPI và Docker integration; [Issue #142](https://github.com/NgaiLong49423/vegetarian-support-system/issues/142), [PR #149](https://github.com/NgaiLong49423/vegetarian-support-system/pull/149).

## Triệu chứng

So sánh runtime OpenAPI với snapshot có thể khác riêng `servers[0].url`: runtime trả `http://127.0.0.1:8080`, snapshot dùng `http://localhost:8080`.

## Hành vi mong đợi

Healthcheck và thao tác capture contract dùng cùng origin Backend chuẩn của stack local/CI, để việc kiểm tra không thay đổi metadata server URL của generated OpenAPI.

## Bằng chứng và tái hiện

Khởi động root Compose trên project riêng `mamxanh-ci142`, không cấu hình provider thật. Đọc `/v3/api-docs.yaml` bằng `http://localhost:8080` rồi parse và so sánh toàn bộ YAML với `docs/api/openapi.yaml`: ghi nhận đúng một khác biệt `/servers/0/url`. Healthcheck baseline gọi `/v3/api-docs` bằng `127.0.0.1`, còn tài liệu, snapshot và CI capture dùng `localhost`.

## Môi trường

Docker Desktop Linux containers, root `docker-compose.yml`, SQL Server/Backend/Frontend thật. Fixture cấu hình riêng, không dùng credential thanh toán của người dùng.

## Nguyên nhân và cách xử lý

Generated server URL phụ thuộc hostname request trong khi các lượt đọc healthcheck và YAML dùng chung tài liệu Springdoc. Thống nhất healthcheck về `http://localhost:8080/v3/api-docs`; giữ nguyên endpoint và assertion so sánh toàn bộ contract, không sửa tay snapshot hoặc bỏ qua trường `servers`.

## Kiểm chứng

Trước sửa đã ghi nhận khác biệt server URL trên Compose thật. Sau khi thống nhất hostname và tạo lại Backend, 3 lần so sánh liên tiếp đều khớp toàn bộ snapshot; SQL Server/Backend/Frontend healthy. Frontend typecheck và parse workflow YAML đạt. Bộ integration dùng chung SQL chạy tuần tự đạt 6 test, 1 test Gemini thật được skip theo cấu hình opt-in có sẵn. CI trên SHA mới chưa kết luận; chưa coi Docker Development là đạt.
